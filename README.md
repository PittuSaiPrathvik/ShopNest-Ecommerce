
# ShopNest - E-Commerce Homepage

## 1. Project Description

ShopNest is an Amazon-inspired e-commerce homepage developed as part of a Full Stack Development training assignment.

The project demonstrates the design and development of a modern online shopping interface using HTML, CSS, and JavaScript.

It includes product listings, search functionality, category filtering, sorting, a shopping cart, and a responsive layout.

## 2. Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Local Storage
- Visual Studio Code
- Git and GitHub

## 3. Features Implemented

- Responsive navigation bar
- Website logo and delivery section
- Product search functionality
- Product category filtering
- Product sorting by price and rating
- Product cards with images and ratings
- Add to Cart functionality
- Shopping cart item counter
- Cart total price calculation
- Remove products from cart
- Automatic promotional banner slider
- Responsive desktop, tablet, and mobile design
- Browser Local Storage for cart data

## 5. How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html.
4. Right-click and select Open with Live Server.
5. The ShopNest website will open in your browser.

## 6. Challenges Faced

- Creating a responsive layout for different screen sizes.
- Implementing dynamic product rendering using JavaScript.
- Managing cart quantities and calculating the total price.
- Implementing product search and category filtering.
- Maintaining a consistent design across different sections.

## 7. Conclusion

ShopNest demonstrates the practical implementation of frontend development concepts through an interactive e-commerce homepage.

The project helped develop skills in HTML, CSS, JavaScript, responsive web design, and GitHub version control.
